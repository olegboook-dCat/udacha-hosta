# Удача — кафе в Хосте

Одностраничный сайт кафе «Удача» (Сочи, Хоста, Платановая ул., 4/4). Статический HTML/CSS/JS без фреймворков и серверных функций.

- `src/` — исходники: `index.html`, `css/style.css`, `js/main.js`, SVG-графика (лист банана, иконка).
- `photos.json` — фото кафе и гостей из карточки на Яндекс Картах (id изображений на avatars.mds.yandex.net).
- `hero/` — фото первого экрана, локальный файл (улучшенная версия снимка веранды из карточки, 1760×1320, AVIF). Лежит в виде base64-частей `hero.avif.b64.1…4`: GitHub-коннектор умеет класть в репозиторий только текст. `build.mjs` склеивает и декодирует их при сборке; остальные фото по-прежнему скачиваются с Яндекса.
- `build.mjs` — собирает готовый сайт в `dist/`: копирует `src/`, скачивает фото и сжимает их в webp (sharp), кладёт шрифты Yeseva One, Manrope и Caveat (кириллица и латиница, woff2 из пакетов @fontsource) прямо в проект, делает иконки и картинку для соцсетей.

```bash
npm install
npm run build   # → dist/
```

Как заменить фото первого экрана:

- проще всего — положить картинку как `hero/hero.jpg` (или `.png`, `.webp`, `.avif`; от 1600 px по ширине, пропорции 4:3). Такой файл используется вместо base64-частей, их можно удалить;
- если файл можно добавить только текстом: `base64 -w 76 photo.avif > hero/hero.avif.b64` (одним файлом или частями `hero.avif.b64.1`, `.2`, … — части склеиваются по номеру), старые части удалить.

Из этого файла сборка делает `hero.webp` (до 1920 px), вертикальный кадр для телефона `hero-m.webp` и картинку для соцсетей `og.jpg`.

Для переноса на свой домен соберите с адресом сайта, чтобы превью ссылки в мессенджерах подхватило картинку: `SITE_URL=https://example.ru npm run build`. На Vercel адрес подставляется сам.

Содержимое `dist/` — обычные файлы, его можно скопировать на любой хостинг (например, Timeweb) как есть. Внешний сервис на странице только один: карта Яндекса (iframe). Google-сервисов и CDN-шрифтов нет.

Данные: название, адрес, телефон, часы, кухни, цены, рейтинг, фото и отзывы взяты из карточки кафе на Яндекс Картах: https://yandex.ru/maps/org/udacha/1252765675/
